# NAPI

## Descripción

NAPI es un RPG por turnos en 2D inspirado en Honkai Star Rail, Marvel Avengers Alliance Redux y Jujutsu Kaisen Phantom Parade.

Este proyecto tiene como objetivo principal aprender desarrollo profesional de videojuegos utilizando Unity 6.

---

## Motor

Unity 6 LTS (6000.5.4f1)

---

## Render Pipeline
