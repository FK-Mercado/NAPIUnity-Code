# NAPI - Development Environment

## Objetivo

Este documento registra el entorno de desarrollo oficial del proyecto NAPI.

Su propósito es garantizar que cualquier computador pueda configurar el proyecto utilizando las mismas versiones y herramientas, evitando incompatibilidades entre desarrolladores o entre diferentes equipos personales.
